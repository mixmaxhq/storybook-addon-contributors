## What it is
A Storybook addon (`@mixmaxhq/storybook-addon-contributors`) that adds a Contributors panel to the Storybook UI, displaying the author(s) of each story's component. Published to npm; consumed by Storybook-based dev environments at Mixmax.

## serves
role: Storybook UI addon — surfaces per-component contributor metadata in the Storybook panel
referenced-by: [any Mixmax repo running Storybook that imports this addon (e.g. monorepo-frontend, component-library consumers)]

## Code map
- Decorator entry point -> `src/index.js` (exports `withContributors`)
- Panel registration -> `src/register.js`
- Addon constants (IDs, event keys) -> `src/constants.js`
- Panel UI component -> `src/Tool.js`
- Compiled output -> `dist/` (generated by `npm run build`)
- Public register shim -> `register.js` (re-exports `dist/register`)

## Conventions
- CommonJS output (`dist/`) compiled from ES module source via Babel; `main` points at `dist/index.js`
- No test suite — no `test` script defined; changes verified manually in a consuming Storybook
- Peer-depends on React (`*`); Storybook v5 APIs (`@storybook/addons`, `core-events`, `components`)
- Publish via `npm publish` (prepublish hook runs the build automatically)

## Gotchas
- `dist/` must be committed or built before publish — `prepublish` runs `babel src -d dist` but the output is gitignored-by-default pattern; verify `dist/` is included in the published package
- Storybook v5 API only — `makeDecorator`, channel, and panel APIs differ in v6+; upgrading requires rewiring `src/register.js` and `src/index.js`
- Contributors are set on the component class (`Button.contributors = [...]`), not via Storybook parameters — this is a non-standard pattern vs. modern `parameters.contributors`

## Run / test
```bash
npm install          # install deps
npm run build        # compile src → dist (Babel)
npm run build:watch  # watch mode during development
# No automated tests — verify manually in a consuming Storybook
npm publish          # publish to npm (runs build first via prepublish)
```
